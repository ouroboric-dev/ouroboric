# Legal

The licence and contribution terms for Ouroboric's public repositories.

## Licences

| What | Licence | Why |
| --- | --- | --- |
| Factory code (Yggdrasil, Asgard, scripts) | AGPL-3.0 | open source; a changed version that is distributed or offered as a service must publish its source, so no closed copy can be sold |
| Anything copied into what operators build (realm templates, Asgard templates, own skills, organisation templates) | MIT | operators' products must stay theirs |
| Documentation | CC BY 4.0 | reuse with credit |
| Names and logos | reserved | see [TRADEMARKS.md](../../../TRADEMARKS.md) |

**What operators build with Ouroboric factories belongs to them.** Templates include a "Built with
Ouroboric" notice by default; keeping it is requested, not required.

**Decided 2026-10-11:** AGPL-3.0 for factory code, MIT for copied templates, CC BY 4.0 for docs, names
and logos reserved. Considered: Apache-2.0 everywhere (allows closed, paid copies) and
source-available licences such as FSL and PolyForm Shield (not open source).

## Contributions

- **Issues only for now:** issues are open on the factories (`yggdrasil`, `asgard`) through issue
  forms; other repos keep issues off. Outside pull requests stay closed until a contributor licence
  agreement is in place. Discussions are open.
- **Before the first outside contribution,** a contributor licence agreement must be in place, so the
  project can keep offering code under more than one licence (for example, closed components later).
- **Code of conduct:** Contributor Covenant 2.1, in the organisation's `.github` repository.
- **Security reports:** GitHub private vulnerability reporting.

This page is not legal advice; a qualified person should review the licence choice.
