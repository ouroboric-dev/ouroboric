# Branding prompts (Nano Banana) — OUROBORIC.DEV

Generated 2026-10-11 in a /btw side session. Concept ties: loop (build→check→fix), graph (nodes/edges),
recursive tree (umbrella→leaf), approval gate (orange notch). Palette: Midnight #0B0D12, International Orange #FF4F00.

Tips: one asset per prompt (attach the chosen icon to later prompts: "using this exact icon…"); quote and
spell exact text (O-U-R-O-B-O-R-I-C-.-D-E-V); state aspect ratio; test a monochrome version.

## 1. Icon exploration (run 3–4×)
A minimalist geometric logo mark for a software factory engine called OUROBORIC.DEV. Concept: an ouroboros loop formed by a directed graph — 6 to 8 solid square nodes connected by thick edges, arranged in a circle so the last node feeds back into the first. One node is split by a narrow vertical notch, suggesting a checkpoint gate. Flat vector, solid fills only, two colors: deep midnight black (#0B0D12) and international orange (#FF4F00) used only on the gate node. Centered on pure white, square 1:1 canvas, generous negative space, no gradients, no shadows, no text.

Alternative "Concept:" lines:
- Recursive: three concentric loops of graph nodes, the inner loop nested inside a node of the outer loop — a fractal ouroboros
- Harness: a closed loop of interlocking rectangular blocks like a conveyor belt seen from above, one orange block acting as a gate
- Tree + loop: a small branching tree of nodes whose top branch curves down and reconnects to its root

## 2. Wordmark
Typography-only wordmark: the text reads exactly "OUROBORIC.DEV". Clean high-end Swiss neo-grotesque sans-serif, medium-bold, slightly tight tracking, all caps. The dot before DEV is a solid international orange (#FF4F00) square; all other letters deep midnight black (#0B0D12). Pure white background, 4:1 canvas, flat vector, no effects, letters spelled exactly O-U-R-O-B-O-R-I-C-.-D-E-V.

## 3. Lockup (attach icon)
Using this exact icon without changing its shape or colors, create a primary logo lockup: icon on the left, the wordmark "OUROBORIC.DEV" to the right, vertically centered, icon height about 1.6× the cap height. Swiss neo-grotesque type, midnight black with an orange square dot. White background, 3:1 canvas, flat vector, ample padding.
(Also ask for: "stacked: icon above, text centered below".)

## 4. Favicon / app icon (attach icon)
Simplify this exact icon to its most essential form for a 32×32 browser favicon: keep only the loop silhouette and the single orange gate node, thicken all strokes for tiny sizes, remove fine details. Solid midnight black on white, plus a second version in white on a midnight black rounded square. Flat, no gradients.

## 5. Dark / terminal version
The same icon and wordmark on a deep midnight black (#0B0D12) background: icon and letters in off-white (#F2F2F0), the gate node and dot in international orange. Subtle 1px dark grey grid lines behind, evoking a terminal UI. 16:9 canvas, flat vector, high contrast, no glow.

## 6. GitHub / README banner (1280×640)
A wide 2:1 banner for a GitHub repository. Left third: the OUROBORIC.DEV icon and wordmark (use attached images exactly). Right two-thirds: a flat isometric diagram of a software factory — small block nodes connected by thin lines flowing through stations (plan, build, check, gate), the line looping back to the start; one station highlighted in international orange. Midnight black linework on white, generous margins, flat vector, no extra text.

## 7. Brand sheet (once assets exist)
A clean brand identity board on white in a 2×3 grid: the icon, the wordmark, the horizontal lockup, the favicon at 64/32/16 px, a dark-mode version, and a palette with two swatches labeled "Midnight #0B0D12" and "International Orange #FF4F00". Swiss grid layout, hairline dividers, small neutral captions, flat vector.

## Follow-up edits
- Keep everything identical but make the edges 30% thicker.
- Remove one node so there are 6; keep the gate node orange.
- Render in pure black only to test monochrome legibility.
- Align every node to a strict 8-point grid for pixel-perfect rendering.

Before settling on the name: check domains, GitHub org names and trademarks for "Ouroboric", and reverse-image-search the final icon (ouroboros loops are a common devtools motif).
